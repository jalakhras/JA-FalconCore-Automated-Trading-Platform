## 0. لماذا R1.1a-fix

تشغيل أبريل لتشخيص R1.1a كشف:
- **خلل:** فجوات شاذّة الحجم (حتى 31,437 نقطة) تجتاز الفلاتر — قفزات
  عطلة أو أخطاء بيانات، ليست فجوات تداول. يجب رفضها قبل بناء الدخول،
  وإلا تلوّث أوّل اختبار صفقات.
- **تنظيم:** مدخلات S00 أسماؤها طويلة ومربكة، وغير مجمَّعة. الوقت
  الأرخص لإصلاح ذلك الآن (الكود في مهده).

R1.1a-fix يعالج الاثنين معًا — تعديل صغير، الكود ما زال اكتشافًا فقط
(لا منطق دخول، فلا خطر خلط منطق).

## 1. الجزء الأول — فلتر الحدّ الأقصى (إصلاح الخلل)

أضِف فلتر حجم رابعًا في `S00_FvgQualityFilter.mqh`:
- مدخل جديد `S00_MaxGap` (قيمة مبدئية **6000**).
- الفجوة التي حجمها `> S00_MaxGap` تُرفَض، سبب الرفض: `MAXSIZE`.
- يُطبَّق مع فلاتر الجودة الأخرى؛ الفجوة تُقبَل فقط إن اجتازت الكلّ.

> القيمة 6000 مبنيّة على بيانات أبريل: تُبقي ~92% من الفجوات المقبولة،
> تقع فوق المئين 90 وتحت الذيل الشاذّ. قابلة للضبط لاحقًا.

تقرير التشخيص `S00_FvgDetection_Diagnostics.csv`: السبب `MAXSIZE` يُضاف
إلى أسباب الرفض الممكنة.

## 2. الجزء الثاني — `AtrPeriod` إلى `#define`

`AtrPeriod` (فترة الـ ATR) قيمة لن نضبطها — 14 معيار راسخ. تطبيقًا
لقاعدة المدخلات (المدخل يحتاج مبرّرًا):
- احذف `AtrPeriod` من المدخلات.
- عرّفه `#define S00_ATR_PERIOD 14` في `S00_ScalpFvgMicroInputs.mqh`
  (أو `Core/FalconConstants.mqh` إن كان أنسب).
- حدّث كود الـ ATR ليستخدم الثابت.

---

## 3. الجزء الثالث — تسمية المدخلات وتجميعها

### 3.1 إعادة التسمية
مدخلات S00 الستّة (بعد الجزء 1 و2) تُسمّى أسماءً قصيرة واضحة ببادئة
`S00_`:

| الاسم القديم | الاسم الجديد |
|---|---|
| `MinGapPoints` | `S00_MinGap` |
| `MaxGapPoints` (جديد) | `S00_MaxGap` |
| `GapAtrMultiplier` | `S00_GapAtrMult` |
| `TrendMaPeriod` | `S00_TrendMA` |
| `GapExpiryBars` | `S00_GapExpiry` |
| `EnableFvgDetectionDiagnostics` | `S00_DiagReport` |

> **النطاق:** تُعاد تسمية مدخلات **S00 الجديدة فقط**. مدخلات المشروع
> القديمة (`EnableMainReport`, `ReportProfile`... من قبل إعادة الهيكلة)
> **لا تُمَسّ** — تنظيفها بند مؤجَّل منفصل (مسجَّل في Backlog من R0.6b §6).

### 3.2 التجميع
نظّم المدخلات بهيكل المجموعات:
```cpp
input group "═══ STRATEGIES ═══"
input bool Enable_S00_FvgScalp = true;   // مفتاح تشغيل/إطفاء S00
// (مفاتيح S01.. تُضاف هنا مستقبلًا — مجموعة واحدة لكل الاستراتيجيات)

input group "── S00 FVG Scalp ──"
input double S00_MinGap      = 30.0;
input double S00_MaxGap      = 6000.0;
input double S00_GapAtrMult  = 0.5;
input int    S00_TrendMA     = 50;
input int    S00_GapExpiry   = 20;
input bool   S00_DiagReport  = false;
```
المبدأ:
- مجموعة رئيسية واحدة `STRATEGIES` تضمّ مفاتيح تشغيل/إطفاء كل
  الاستراتيجيات (الآن S00 فقط؛ S01.. لاحقًا).
- مجموعة فرعية لكل استراتيجية بمدخلاتها (الرموز/المسافات تحاكي التسلسل
  الهرمي — MQL5 لا يدعم مجموعات فرعية حقيقية).

> `Enable_S00_FvgScalp` مفتاح جديد — في R1.1a/fix الاستراتيجية غير
> مُفعَّلة فعليًّا (لا دخول)، لكن المفتاح يُعرَّف الآن ليكون جاهزًا، ويوضع
> في مجموعته الصحيحة. لا يربط منطقًا بعد.
