### مواصفات للتسليم إلى Claude Code

> **الهدف:** تنظيف التعليقات الظاهرة لمدخلات S00 السبعة — وصف وظيفيّ
> نظيف، بلا أرقام مراحل أو ملاحظات تطوير.

---

## 0. لماذا R1.1a-labels

في MQL5، التعليق المكتوب بعد المدخل (`input ... ; // تعليق`) هو **ما
يظهر للمستخدم** في نافذة الإعدادات — لا اسم المتغيّر. أي **التعليق هو
الاسم الظاهر فعليًّا**.

تشغيل النسخة الحالية كشف أن تعليقات مدخلات S00 السبعة فوضى — تحوي أرقام
مراحل وملاحظات تطوير وجملًا مقطوعة (مثل "R1.1a-fix: declared now; wired
to the chain in R1.1b"). هذا يخالف قاعدة المدخلات، ويجعل النافذة غير
مفهومة — حتى أن مفتاح تقرير التشخيص لم يُعرَف.

R1.1a-labels تصحيح صغير: تنظيف التعليقات السبعة فقط. **لا تغيير منطق، لا
تغيير أسماء متغيّرات، لا تحريك مجموعات.**

> **النطاق:** مدخلات S00 السبعة فقط. مدخلات المشروع القديمة المربكة لا
> تُمَسّ — تنظيمها الشامل بند مرحلة `R1.x` مخصّصة (مسجَّل في Backlog).

---

## 1. التعليقات النظيفة — الجدول

أعِد كتابة التعليق الظاهر لكل مدخل من السبعة. **الاسم البرمجي للمتغيّر
لا يتغيّر** — فقط نصّ التعليق بعد `//`.

| المتغيّر (لا يتغيّر) | التعليق الظاهر الجديد |
|---|---|
| `Enable_S00_FvgScalp` | `Enable the S00 FVG Scalp strategy` |
| `S00_MinGap` | `Minimum FVG size to trade (points)` |
| `S00_MaxGap` | `Maximum FVG size - rejects abnormal gaps (points)` |
| `S00_GapAtrMult` | `FVG strength filter: gap >= ATR x this value` |
| `S00_TrendMA` | `Trend filter SMA period (M5)` |
| `S00_GapExpiry` | `Bars before an untouched FVG expires` |
| `S00_DiagReport` | `S00 FVG detection diagnostic report (on/off)` |

القواعد المطبَّقة: وصف وظيفيّ قصير، إنجليزية بسيطة، **ممنوع** رقم مرحلة
(`R1.1a`, `v0.57`...) أو ملاحظة تطوير (`declared now`, `wired in...`,
`Reserved for...`) أو جملة مقطوعة.

---

## 2. القيود الصارمة

- تغيير **نصّ التعليق فقط** — لا تغيير لاسم أي متغيّر.
- لا تغيير قيمة أي مدخل، لا منطق، لا مجموعات.
- لا لمس مدخلات المشروع القديمة — السبعة فقط.
- مجموعة `STRATEGIES` تبقى في موضعها (أعلى النافذة) — لا تحريك.
- صفر تغيير سلوك — تشغيل FixedLot April يبقى
  `585.17 / 1104.89 / 157.49`.

---

## 3. تحديث `EA_VERSION_TAG`

في `Core/FalconConstants.mqh`، حدّث `EA_VERSION_TAG` إلى `R1_1a_labels`.

## 4. بروتوكول العمل

1. راجع نافذة Problems؛ ترجمة F7 الحَكَم.
2. أفكار التحسين → `Docs/Ideas_Backlog.md`.
3. حدّث `Docs/ReviewNotes/R1_1a_Review_Notes.md`.

> **سجّل في `Docs/Ideas_Backlog.md`** — إضافة لقاعدة المدخلات الثالثة:
> "التعليق الظاهر للمدخل (الذي يراه المستخدم في النافذة) جزء من الاسم —
> وصف وظيفيّ نظيف؛ ممنوع أرقام المراحل أو ملاحظات التطوير أو الجمل
> المقطوعة."
>
> **سجّل أيضًا — بند مرحلة مستقلّة:** "مرحلة R1.x — إعادة تنظيم شاملة
> لكل مدخلات المشروع القديمة (أسماء + تعليقات + مجموعات). مرحلة مخصّصة
> مستقلّة، لا تُخلَط ببناء استراتيجية. أولوية مرتفعة."

## 5. معايير القبول

- التعليقات الظاهرة للمدخلات السبعة مطابقة لجدول §1.
- لا اسم متغيّر تغيّر؛ لا قيمة تغيّرت؛ لا منطق تغيّر.
- مدخلات المشروع القديمة لم تُمَسّ.
- يُترجَم: `0 errors, 0 warnings`.
- تشغيل FixedLot April يبقى `585.17 / 1104.89 / 157.49`.
- `EA_VERSION_TAG` = `R1_1a_labels`.
- ملف المراجعة + Backlog محدَّثان.

## 6. بعد R1.1a-labels

عند نجاح الترجمة → **commit واحد**:
```
git add -A
git commit -m "R1.1a - clean S00 input display comments"
```

الاكتشاف للتحقّق — وبعده R1.1b (منطق الدخول).
