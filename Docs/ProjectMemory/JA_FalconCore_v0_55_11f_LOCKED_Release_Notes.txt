JA FalconCore v0.55.11f — Session Boundary User Override Inputs
Status: LOCKED / ACCEPTED

Purpose
- Add a user-controlled optional No-New-Entry guard before daily/session close.
- Default is OFF to preserve baseline performance.
- When enabled, the guard applies directly to Paper results before Emergency and Capital Flow.
- Default user override window: 1 minute.

Inputs Added
- EnableNoNewEntriesBeforeClose = false
- NoNewEntriesBeforeCloseMinutes = 1

Decision
- Lock the feature as optional user safety override.

- User may manually enable it for exceptional risk concerns, with a default of 1 minute.
- This is not a strategy improvement layer; it is a user-controlled operational safety override.
